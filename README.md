# FB-Clone

A Facebook-inspired social media web application built to recreate the core look and feel of Facebook.

## 📌 About the Project

FB-Clone is a social media application created for learning and practicing web development. It aims to replicate Facebook's user interface and common social networking features.

## ✨ Features

- 🏠 Facebook-inspired home page
- 👤 User profile interface
- 📰 News Feed UI
- 👍 Like and comment interface
- 📝 Create post interface
- 👥 Friends and connections section
- 📱 Responsive user interface
